# IT3040 Assignment 1 - Transliteration Accuracy Testing

## Project Description
This project automates negative test cases for the Pixelssuite Chat Sinhala transliteration function using Playwright and Python.

## Prerequisites
- Python 3.11 or 3.12
- Google Chrome
- Playwright
- openpyxl

pip install -U pip
pip install playwright openpyxl
