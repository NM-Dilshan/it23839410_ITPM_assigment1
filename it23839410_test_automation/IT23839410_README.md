# IT3040 Assignment 1 - Transliteration Accuracy Testing

## Project Description
This project automates negative test cases for the Pixelssuite Chat Sinhala transliteration function using Playwright and Python.

## Prerequisites
- Python 3.11 or 3.12
- Google Chrome
- Playwright
- openpyxl

## Installation
```bash
pip install -U pip
pip install playwright openpyxl
playwright install

##Run command
python IT23839410_test_automation.py --excel "IT23839410_Assignment 1 - Test cases.xlsx" --url "https://www.pixelssuite.com/chat-translator" --wait-ms 5000 --type-delay-ms 80 --slow-mo-ms 200 --save-every 1 --keep-open
